# TÉRMINOS Y CONDICIONES DE SERVICIO
**Aplicación:** EntrevistaApp / Rukan
**Versión:** 1.0.0
**Última actualización:** Septiembre 2026

Bienvenido a EntrevistaApp. Estos Términos y Condiciones rigen el acceso y uso de la plataforma móvil y web de simulación y preparación de entrevistas laborales.

---

### 1. CUENTAS DE USUARIO
Para acceder a las simulaciones de entrevista y seguimiento de historial, el usuario debe registrarse proporcionando una dirección de correo electrónico válida y una contraseña segura. El usuario es responsable de mantener la confidencialidad de sus credenciales.

### 2. PLANES FREEMIUM Y SUSCRIPCIONES PREMIUM
- **Capa Freemium:** Permite la práctica de preguntas abiertas con retroalimentación instantánea a través del Motor NLP local (sin costo de API ni consumo de tokens).
- **Capa Premium / Suscripciones:** Ofrece simulaciones avanzadas con voz en tiempo real, análisis multimodal y reportes detallados gestionados mediante Google Play Billing.

### 3. CANCELACIÓN Y REEMBOLSOS
Las compras dentro de la aplicación y las renovaciones se gestionan de conformidad con las políticas de Google Play Store.

### 4. CONDUCTA DEL USUARIO
El usuario se compromete a no utilizar lenguaje difamatorio, ilegal o fraudulento en sus respuestas grabadas o escritas.
